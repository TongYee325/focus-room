# 专注训练室 · Focus Room

在线访问：https://focus-room-training.social-dell-7370.chatgpt.site

电脑优先、兼容触屏的夜间主题认知训练网页。提供舒尔特方格、色卡冲突、序列记忆（空间 / 数字）和动态追踪。舒尔特方格与色卡冲突支持简单、普通、困难、专家四档；序列记忆和动态追踪另有极限档。

## 本地启动

需要 Node.js 22.13 或更高版本。Windows 下可直接双击 `启动训练室.cmd`，保持启动窗口开启，再在浏览器打开终端显示的本地地址，通常为 **http://localhost:3000/**。

也可在此目录执行：

```powershell
npm.cmd ci
npm.cmd run dev
```

已安装依赖时只需要第二条命令。使用 `npm.cmd` 可以避免 Windows 的 PowerShell 执行策略或 npm.ps1 配置影响。若 3000 端口已被占用，以启动窗口实际显示的地址为准。关闭终端或按 Ctrl+C 停止运行。

## 训练与操作

| 训练 | 规则 | 操作 |
| --- | --- | --- |
| 舒尔特方格 | 从 1 开始升序完成一张随机方格 | 点击数字，也可使用 Tab 与回车 |
| 色卡冲突 | 在 60 秒内判断文字实际显示的颜色 | 点击颜色名称或按 1–4；专家档支持 1–6 |
| 空间记忆 | 观察九宫格闪烁序列，再正序复现，共 5 轮 | 点击方块或按 1–9；Backspace 撤销，Enter 提交 |
| 数字记忆 | 观察逐个出现的数字，再正序复现，共 5 轮 | 数字键或屏幕键盘；Backspace 撤销，Enter 提交 |
| 动态追踪 | 记住高亮目标，在混合移动结束后找回，共 5 轮 | 点击目标；也可 Tab 选择焦点、空格切换选中 |

Esc 暂停 / 继续；页面失去焦点或切换标签页时自动暂停。暂停会遮盖内容并冻结时钟；恢复前有 3 秒倒计时。记忆与追踪的轮间结果等待不计入有效训练时长。

音效默认开启，可通过右上角音量按钮关闭；无背景音乐。首次点击开始后浏览器才会启用音效。

极限档序列记忆：空间序列 10 项、数字序列 12 项，每项展示 250 毫秒，间隔 200 毫秒。极限档动态追踪：16 个小球中追踪 7 个目标，移动 20 秒，初始速度为场地短边的 38% / 秒。两项均为每局 5 轮，成绩按难度独立记录。

## 成绩保存

数据使用当前浏览器的 localStorage，键为 `focus-room:v1`。保留最近 200 局，同时独立保存个人最佳与累计训练次数、时长。最佳成绩按训练、难度及记忆子模式分别比较。

成绩、音效设置均保存在本机。不同浏览器或不同网页地址（包括端口）有各自的记录；清除网站数据会清除记录。存储不可用时仍能完成训练，页面会提示保存状态。未完成的训练不记入成绩。

## 开发与验证

使用 Sites 标准 Vinext / React 19 / TypeScript 项目，界面复用随模板安装的 Shadcn / Base UI 组件。训练逻辑在客户端运行，第一版无需数据库或在线部署。

```powershell
npm.cmd run typecheck
npm.cmd run lint
npm.cmd test
npm.cmd run build
```

- `lib/training/config.ts`：玩法信息和全部难度参数。
- `lib/training/engine.ts`：可确定性测试的训练状态机、计时、序列和小球物理逻辑。
- `lib/training/storage.ts`：分类型成绩、最佳比较、本地存储及异常处理。
- `hooks/use-training.ts`：统一页面状态、动画时钟、键盘、暂停和单次结算。
- `components/training/`：菜单、设置、训练区域、结算和历史界面。
- `tests/`：训练逻辑、组件流程、存储和 WebMCP 契约测试。

Lint 覆盖应用代码与测试；模板自带的 `components/ui` 组件和 `hooks/use-mobile.ts` 保持原样。TypeScript 检查覆盖完整项目。

支持 `document.modelContext` 的浏览器会注册 `configure_training`、`start_training`、`read_training_state` 三个 WebMCP 接口。它们使用与页面相同的状态和操作，拒绝无效参数及覆盖正在进行的训练；公开状态不包含记忆答案、追踪目标身份或随机种子。不支持该接口的浏览器正常运行。

产品文字描述练习规则与训练指标，不承诺医学效果。
